# 第一个角色善恶值卡牌设计

日期：2026-06-13

本文档记录第一个角色围绕“善恶值”机制设计的 52 张卡牌草案。

当前内容是 v0.1 设计稿，用于讨论卡牌方向、稀有度分布、善恶值玩法密度和变身卡差异。本文档不代表当前工程已经实现这些卡牌。

## 设计前提

- 善恶值是单轴对立数值：正数为善，负数为恶，0 为中立。
- 文档中的“本战 +N 善”表示本场战斗临时增加善恶值。
- 文档中的“本战 +N 恶”表示本场战斗临时向恶方向变化。
- 文档中的“本回合 +N 善 / 恶”表示回合结束时撤回。
- 能力牌打出后获得能力，不进入弃牌堆，也不进入除外堆，而是直接离开牌堆。
- 技能牌可理解为非攻击、非防御的行动牌，可以承担攻击、防御、抽牌、调节善恶值等功能。
- 变身卡打出后由变身状态持有，解除变身后进入弃牌堆。

## 初步设计意图

普通卡牌主要承担基础出牌体验：

- 小幅推动善或恶。
- 提供基本攻击和防御。
- 给玩家少量“转向”“归零”“选择善恶”的操作。

罕见卡牌开始强化流派：

- 善流派偏防御、稳定、赦免和护盾。
- 恶流派偏攻击、连击、爆发和代价。
- 中立或双相流派偏抽牌、返费和方向切换。

稀有卡牌提供构筑核心：

- 高阈值善牌提供稳定强化。
- 高阈值恶牌提供更高爆发和额外代价。
- 双相牌鼓励在善恶之间反复切换，或保持接近中立。

## 后续待讨论

- 第一个角色的主流派是否更偏善、偏恶，还是偏善恶切换。
- 三张变身卡是否都应该进入同一角色牌池，还是拆成不同角色或不同路线。
- 能力牌离开牌堆后是否需要进入一个隐藏的“能力区”，用于 UI 展示当前已生效能力。
- 善恶值永久变化是否来自战斗结算、剧情选项、击杀敌人，还是某些稀有卡牌。
- 善恶阈值是否需要统一为 3 / 6 / 10 / 12 这类档位，方便玩家记忆。
