## 策划表管线

本项目采用策划表驱动。

```text
Excel 工作簿用于编辑和查看
CSV 文件用于 Godot 读取
Godot 脚本负责把 CSV 转换为运行时数据
```

当前 Excel 源表目录：

```text
design_tables/excel/
```

其中 `Enum.xlsx` 是策划查阅用枚举说明表，不导出为运行时 CSV。

当前 CSV 表：

```text
data/tables/Character.csv

data/tables/CardTypeConfig.csv
data/tables/EnemyIntentConfig.csv
```

导出工具：

```text
导出策划表到CSV.bat
```

正常流程是先修改 `design_tables/excel` 下的 Excel 源表，再运行 bat 导出英文 CSV。Godot 只读取 `data/tables` 下的英文 CSV。
