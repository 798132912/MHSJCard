# 善恶值机制设计

日期：2026-06-10

本文档记录“善恶值”机制的规则草案，用于后续设计卡牌、变身卡和相关效果。

当前内容仅作为设计沉淀，后续可以根据卡牌设计和试玩反馈继续调整。本文档不代表当前工程已经实现该机制。

## 设计定位

善恶值是角色身上的特殊数值机制，用于表现角色在战斗和剧情选择中的倾向变化。

它可以被卡牌、变身卡、事件、战斗结算或其他系统改变，也可以被卡牌用作使用条件、效果分支、效果倍率和形态规则。

善恶值与当前已有的“堕落值”暂时并存：

- 善恶值不替代堕落值。
- 堕落值暂时不迁移到善恶值。
- 后续如果需要合并或联动，需要单独设计。

## 核心规则

善恶值是一个单轴对立数值。

```text
N = 善 N
-N = 恶 N
0 = 中立
```

示例：

```text
当前善恶值 = +2
获得 4 点恶 = -4
最终善恶值 = -2
显示为：恶 2
```

善和恶不会作为两个独立数值同时显示。它们会在同一条数值轴上互相抵消。

## 显示规则

善恶值在 UI 或效果栏中只显示一个结果。

```text
善恶值 > 0：显示 善 N
善恶值 < 0：显示 恶 N
善恶值 = 0：不显示
```

图标可以根据当前方向变化：

- 善值大于 0 时使用善图标。
- 恶值大于 0 时使用恶图标。
- 中立时默认不占用效果栏图标。

如果后续需要强调中立状态，可以再增加中立图标，但第一版暂定不显示。

## 来源类型

善恶值可以来自不同来源。

### 永久善恶

永久善恶是角色或本局流程中的基础善恶倾向。

它可能来自：

- 战斗结束后的选择。
- 是否击杀敌人。
- 事件奖励或惩罚。
- 特殊卡牌或遗物的长期效果。

第一版如果需要实现永久善恶，可以先作为运行时或本局基础值记录。等结算层、地图层和存档层稳定后，再接入真正的长期保存。

### 临时善恶

临时善恶由卡牌、状态或变身期间规则提供。

常见持续时间包括：

```text
当前回合
当前变身期间
本场战斗
指定 N 回合
指定状态存在期间
```

所有善恶效果都必须明确持续时间。

善恶效果不设置默认持续时间，避免后续卡牌设计时产生歧义。

## 临时值结算

每个临时善恶效果都应该作为独立来源记录。

示例：

```text
卡牌 A：当前回合 +4 恶
卡牌 B：本场战斗 +2 善
```

结算时应该保留两条来源：

```text
来源 A：-4，当前回合结束时到期
来源 B：+2，本场战斗结束时到期
```

当前回合结束时，只移除来源 A。

```text
移除前：-4 + 2 = -2，显示 恶 2
移除后：+2，显示 善 2
```

不建议只保存一个临时净值。否则当不同持续时间的善恶来源混在一起时，系统很难正确撤回已经到期的部分。

## 卡牌交互

善恶值可以参与卡牌使用和效果结算。

### 使用条件

卡牌可以要求角色达到指定善恶倾向后才能使用。

示例：

```text
恶 >= 3 才能使用
善 >= 5 才能使用
善恶值为恶时才能使用
善恶值为善时才能使用
```

内部判断可以按单轴数值处理：

```text
善 >= 3 等价于 善恶值 >= 3
恶 >= 3 等价于 善恶值 <= -3
```

### 效果分支

同一张卡牌可以根据善恶方向产生不同效果。

示例：

```text
如果当前为善：获得护盾
如果当前为恶：造成伤害
如果当前中立：抽 1 张牌
```

### 数值倍率

卡牌效果可以根据善恶值提高或降低。

示例：

```text
善越高，治疗越强
恶越高，伤害越强
每 2 点善，获得 1 点额外护盾
每 3 点恶，造成 1 点额外伤害
```

### 额外加成

善恶值也可以触发固定阈值加成。

示例：

```text
善 >= 10 时，伤害 +3
恶 >= 10 时，获得额外攻击次数
```

## 变身卡扩展

变身卡可以附带当前变身期间的额外善恶规则。

这些规则属于该变身卡的效果，而不是全局统一规则。

示例：

```text
打出某张变身卡后：
- 获得魔力防御。
- 提高魔力上限。
- 进入魔法少女形态。
- 当前变身期间，如果恶 >= 10，强制解除变身。
- 当恶 >= 10 时，不能再次通过这张卡进入变身。
- 当前变身期间，如果善 >= 10，造成的伤害 +3。
```

不同变身卡可以拥有不同的善恶规则。

例如：

```text
纯白形态：善越高，防御越强；恶过高时解除变身。
暗月形态：恶越高，伤害越强；善过高时解除变身。
平衡形态：善恶绝对值过高时解除变身，中立时获得额外收益。
```

## 变身解除与封锁

善恶导致的变身解除由变身卡效果决定。

如果某张变身卡配置了“恶 >= 10 时解除变身”，则只有该变身卡维持的形态受这条规则影响。

解除后是否禁止再次变身，也由该变身卡效果决定。

当前草案采用：

```text
条件存在期间封锁变身。
```

示例：

```text
某变身卡规则：恶 >= 10 时不能变身

当前恶 = 12：
不能使用该变身卡进入变身。

当前恶降到 9：
可以再次尝试使用该变身卡进入变身。
```

## 与当前 Demo 的兼容原则

后续如果把善恶值机制落实到代码中，需要遵守以下原则：

- 不影响当前已有卡牌的默认行为。
- 不修改旧卡牌的效果含义。
- 不让没有善恶配置的卡牌、敌人、状态受到善恶系统影响。
- 善恶条件、善恶 UI 和变身额外规则只在相关数据存在时启用。
- 优先新增表字段、效果类型或配置项，不把旧逻辑改成强依赖善恶系统。

也就是说，善恶值机制应该是一个可选扩展系统。

当前 demo 即使完全没有配置善恶值，也应该继续按现有规则运行。

## 后续实现建议

后续实现时可以考虑以下运行时结构：

```text
permanent_alignment: int
alignment_modifiers: Array
```

临时来源可以记录：

```text
source_id
source_name
value
duration_type
duration_value
owner_transform_card_id
expire_timing
```

最终善恶值计算：

```text
当前善恶值 = permanent_alignment + 所有未到期临时来源 value 之和
```

后续表格层可以逐步支持：

```text
善恶修改效果
善恶使用条件
善恶条件分支
善恶倍率修正
变身期间善恶规则
战斗结束永久善恶变化
```

这些内容只作为后续实现方向，不要求第一版一次全部完成。
