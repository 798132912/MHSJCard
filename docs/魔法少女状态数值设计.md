# 魔法少女状态数值设计

日期：2026-06-20

本文档记录“魔法少女身上的多维状态数值”设计草案。

当前内容用于后续敌人、事件选项、奖励和卡牌设计讨论，不代表所有数值都已经进入当前 demo。

## 设计目标

原设计中，发情值是唯一比较突出的特殊数值。后续改为：

- 魔法少女身上可以同时存在多种状态数值。
- 敌人的攻击、负面行动和行为逻辑可以读取这些数值，并根据数值改变效果。
- 战斗外选项、奖励选项、剧情选项也可以读取这些数值，决定选项是否出现、代价是否变化、结果是否分支。
- 发情值仍然存在，但不再是唯一核心压力来源。

这些数值不等同于普通状态。它们更接近角色的长期或半长期状态档案，用来让敌人和事件持续“记住”玩家的变化。

## 与现有系统的关系

### 与善恶值

善恶值仍然是一个单轴对立机制，主要服务第一个角色的卡牌构筑、变身卡和善恶分支。

多维状态数值不是善恶值的替代品。

- 善恶值：偏卡牌流派、变身分支、角色立场。
- 状态数值：偏敌人压迫方式、选项条件、角色被影响的方向。

两者可以互相联动，但第一版不要强绑定。

示例：

```text
当前为恶，并且堕落值 >= 30：
  某张牌获得额外效果

恐惧值 >= 20：
  某个事件选项消失
```

### 与普通状态

普通状态通常是短期战斗效果，例如易伤、虚弱、反射、临时火力。

状态数值可以跨回合、跨战斗，甚至在后续版本中跨章节保存。

示例：

```text
易伤：持续 2 回合，影响受到伤害
恐惧值：可能持续整场战斗，或作为局内数值保留到下一场战斗
```

### 与发情值

发情值仍然是其中一个状态数值，但不再单独承担所有特殊压力。

敌人可以选择攻击不同数值：

```text
魅惑类敌人：主要提高发情值和敏感值
压迫类敌人：主要提高恐惧值
诱导类敌人：主要提高依赖值和堕落值
羞辱类敌人：主要提高羞耻值
```

## 首批建议数值

首批不需要一次性全部实现。建议先把系统设计成可扩展，再根据第一章敌人决定实际启用哪些数值。

### 发情值

表示角色的特殊累积压力。

用途：

- 影响卡牌条件、选项条件和单独配置的效果。
- 达到上限时触发高潮状态或强制结束当前回合。
- 可以作为敌人攻击追加效果的参考数值。

第一版可以继续沿用现有规则。

### 敏感值

表示角色对发情类效果的放大程度。

用途：

- 放大受到的发情值。
- 作为部分敌人行动的条件。
- 作为部分卡牌或事件选项的风险因子。

示例：

```text
如果敏感值 >= 30：
  敌人的“催眠光线”额外提高发情值
```

### 堕落值

表示角色被污染、诱导或偏离原本立场的程度。

用途：

- 影响事件选项和奖励选项。
- 作为部分卡牌的使用条件或效果分支。
- 影响敌人的诱导类行动。

示例：

```text
堕落值 >= 40：
  事件中出现“接受交易”选项
```

### 恐惧值

表示角色被压制、威吓或动摇的程度。

用途：

- 敌人的压迫类攻击可以根据恐惧值提高伤害或附加负面状态。
- 恐惧值过高时，部分强硬选项不可选。
- 部分防御牌可以降低恐惧值或利用恐惧值获得收益。

示例：

```text
敌人攻击：造成 6 点伤害。
如果恐惧值 >= 20：
  额外施加 1 层虚弱。
```

### 羞耻值

表示角色的心理失衡、动摇或被迫暴露弱点的程度。

用途：

- 敌人的羞辱类行动可以提高羞耻值。
- 羞耻值可以影响某些卡牌的费用、抽牌或防御收益。
- 战斗外选项可以根据羞耻值改变可选项或结果。

示例：

```text
羞耻值 >= 30：
  某些公开行动选项需要额外代价
```

### 依赖值

表示角色对某个力量、敌人话术或外部帮助的依赖程度。

用途：

- 诱导类敌人可以提高依赖值。
- 依赖值可以让某些负面选项更容易出现，也可以让某些帮助类选项更强。
- 可以作为长期构筑风险，让玩家在短期收益和长期代价之间选择。

示例：

```text
依赖值 >= 25：
  战斗结束奖励中出现“接受额外力量”选项，但会提高堕落值
```

## 数值持续时间

每种状态数值都必须明确持续范围。

建议支持：

```text
当前回合
本场战斗
当前变身期间
本次章节
永久或存档长期
```

第一版建议：

- 发情值、敏感值、堕落值沿用现有设计，可以先作为局内或长期数值。
- 新增数值先以“本场战斗”或“本次章节”为主，不急着接入存档。
- 所有卡牌和敌人行动必须明确写清楚该数值是否战斗结束后保留。

## 敌人联动规则

敌人行动可以与状态数值发生四类联动。

### 数值增加

敌人行动直接提高某个状态数值。

示例：

```text
催眠光线：提高 8 点敏感值
压迫凝视：提高 10 点恐惧值
腐化低语：提高 6 点堕落值
```

### 按数值强化

敌人行动根据玩家当前数值提高效果。

示例：

```text
恐惧撕裂：造成 5 点伤害；恐惧值每 10 点，额外 +1 伤害。
魅惑触碰：提高 6 点发情值；敏感值每 20 点，额外 +1 发情值。
```

### 阈值分支

敌人行动在某个数值达到阈值后追加效果。

示例：

```text
如果堕落值 >= 30：
  额外施加 1 层易伤

如果羞耻值 >= 25：
  玩家下回合第一张牌费用 +1
```

### 行为选择

敌人 AI 根据玩家数值选择下回合行动。

示例：

```text
如果恐惧值 < 20：
  使用 压迫凝视
否则如果敏感值 < 30：
  使用 催眠光线
否则：
  使用 袭击
```

这类逻辑属于敌人 AI 或敌人行为配置，不应该写死在具体 UI 场景里。

## 选项联动规则

战斗外选项可以读取状态数值。

### 选项显示条件

某些选项只有在指定数值达到或低于阈值时出现。

示例：

```text
堕落值 >= 30：
  出现“接受低语中的力量”

恐惧值 <= 10：
  出现“正面质问敌人”
```

### 选项禁用条件

某些选项仍然显示，但因为数值不满足条件而不可选。

示例：

```text
需要恐惧值 < 20
当前恐惧值过高，无法选择
```

### 选项结果分支

同一个选项可以根据数值产生不同结果。

示例：

```text
选择“调查异常法阵”

如果敏感值 >= 30：
  获得更强奖励，但提高发情值
否则：
  获得普通奖励
```

### 选项代价变化

选项的代价可以根据数值变化。

示例：

```text
净化自身：
  基础代价：失去 6 点生命
  如果堕落值 >= 40：额外失去 4 点生命
```

## UI 表示

状态数值会比当前发情/敏感/堕落更多，因此 UI 不应该把所有数值都永久展开成大文本。

建议：

- 战斗主界面只显示当前战斗最关键的数值。
- 其他数值放在可展开的角色状态面板中。
- 敌人意图如果会受某个数值影响，需要在意图详情中显示原因。
- 选项界面可以在选项旁显示条件或变化来源。

示例：

```text
意图：恐惧撕裂
造成 5 + 2 点伤害
来源：恐惧值 24
```

## 后续实现原则

后续落实代码时，需要遵守以下原则：

- 先做通用状态数值系统，不为每个数值写一套完全独立逻辑。
- 数值 ID、显示名、图标、上限、默认持续范围应尽量数据化。
- 敌人 AI 和事件选项通过统一查询接口读取数值。
- 没有配置这些数值的旧敌人、旧卡牌、旧选项不受影响。
- 第一版可以先把新增数值放在运行时和局内存档中，等章节与存档层稳定后再决定哪些数值长期保存。

建议后续模块：

```text
scripts/combat/character_metric_system.gd
scripts/run/choice_condition_resolver.gd
```

`character_metric_system.gd` 负责数值增减、持续时间、上限、查询和文本展示。

`choice_condition_resolver.gd` 负责选项显示条件、禁用条件、结果分支和代价变化。
