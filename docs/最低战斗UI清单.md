# 魔法少女卡牌游戏最低战斗 UI 清单

日期：2026-05-19

本文档记录最低可玩战斗所需 UI、显示字段、交互状态和建议 Godot 节点命名。

相关文档：

- 设定、主题和资源含义：`游戏设定文档.md`
- 底层结算、牌区和公式：`规则机制文档.md`
- 卡牌效果库和卡牌效果组合：`卡牌效果文档.md`
- 敌人数据、敌人卡牌和敌人行为逻辑：`敌人设计文档.md`

本文档内容均为暂定，后续可以根据 Axure 原型和 Godot 实现继续修改。

## 目标

最低战斗 UI 的目标是支撑一场单敌人基础战斗。

第一版只追求：

- 玩家能看懂当前资源。
- 玩家能看到敌人状态和敌人意图。
- 玩家能出牌、选择目标、结束回合。
- 玩家能看到抽牌堆、弃牌堆、消耗区。
- 玩家能通过状态图标看到是否处于变身状态。
- 开发时能通过战斗日志确认规则结算是否正确。

第一版不追求：

- 华丽动画。
- 完整地图。
- 商店。
- 奖励界面。
- 卡组浏览。
- 多敌人复杂布局。
- 完整 tooltip 系统。

## 战斗主界面布局

建议最低战斗界面分为 6 个区域：

```text
敌人状态区
战斗中央区
玩家状态区
手牌区
牌堆信息区
操作区
```

示意：

```text
┌────────────────────────────────────┐
│ 敌人状态区                         │
│ 堕落的学生 / HP / 护盾 / 意图       │
├────────────────────────────────────┤
│ 战斗中央区                         │
│ 目标区域 / 简单反馈 / 战斗日志       │
├────────────────────────────────────┤
│ 玩家状态区                         │
│ HP / 魔力 / 形态 / 护盾 / 特殊属性   │
├────────────────────────────────────┤
│ 手牌区                             │
│ 卡牌 1 / 卡牌 2 / 卡牌 3 ...        │
├────────────────────────────────────┤
│ 牌堆信息区 + 操作区                 │
│ 抽牌堆 / 弃牌堆 / 消耗区 / 结束回合  │
└────────────────────────────────────┘
```

Axure 原型可以不完全按这个布局，但需要保留这些信息位。

## Axure 示意图理解记录

当前 Axure 示意图可以理解为左右对峙式战斗界面。

### 整体结构

```text
左侧：玩家操作角色
右侧：敌人
底部左侧：玩家魔力值与当前手牌
底部右侧：牌堆信息、结束回合按钮、战斗日志
角色下方：生命、防御、状态图标等战斗信息
敌人上方：敌人意图
```

### 玩家区域

玩家区域位于界面左侧。

包含：

```text
玩家角色图像
玩家生命或防御数值条
玩家状态图标
玩家魔力值
当前手牌展示
```

示意图中的左下圆形区域理解为：

```text
魔力值显示
```

示意图中的玩家角色下方小圆点理解为：

```text
状态图标区域
```

### 敌人区域

敌人区域位于界面右侧。

包含：

```text
敌人图像
敌人生命或防御数值条
敌人状态图标
```

敌人下方小圆点理解为：

```text
敌人状态图标区域
```

新版示意图已经在敌人上方预留：

```text
敌人意图
```

后续可以在敌人意图附近继续补充意图数值。

### 卡牌区域

示意图底部偏左位置是一张卡牌的结构样式。

卡牌包含：

```text
消耗
卡牌图像
卡牌效果
卡牌类别
```

这可以作为 `CardView` 的基础结构。

对应建议节点：

```text
CardView
  CostLabel
  ArtTexture
  DescriptionLabel
  TypeLabel
```

### 牌堆区域

示意图右下角包含：

```text
除外堆
弃牌堆
```

其中：

```text
除外堆 = 消耗区
弃牌堆 = 弃牌堆
```

新版示意图已经补充：

```text
抽牌堆
战斗日志
回合结束按钮
```

变身暂存区不需要作为 UI 牌区显示。变身作为状态处理，通过玩家状态图标显示。

### 当前示意图需要后续补充或明确的 UI

基于最低战斗需求，当前示意图后续还需要明确：

```text
玩家当前魔力 / 魔力上限
玩家魔力护盾
玩家魔力防御
玩家当前形态
玩家发情值
玩家敏感值
玩家堕落值
敌人生命值
敌人魔力护盾
抽牌堆数量
除外堆数量
弃牌堆数量
战斗日志显示内容
回合结束按钮状态
```

后续你在 Axure 里命名时，不一定要完全照这个节点名，但最好能对应这些区域。

## 玩家状态区

玩家状态区必须显示：

```text
生命值
当前魔力 / 魔力上限
魔力护盾
魔力防御
当前形态
发情值
敏感值
堕落值
当前状态
```

### 字段说明

生命值：

```text
显示格式：生命值 当前值 / 最大值
示例：生命值 70 / 70
```

魔力：

```text
显示格式：魔力 当前值 / 上限
示例：魔力 3 / 3
```

魔力护盾：

```text
显示格式：魔力护盾 数值
示例：魔力护盾 5
```

魔力防御：

```text
显示格式：魔力防御 数值
示例：魔力防御 70
```

当前形态：

```text
人类形态
魔法少女形态
```

特殊属性：

```text
发情值：0 / 100
敏感值：0
堕落值：0
```

当前状态：

```text
变身状态
高潮状态
其他状态
```

### 建议节点命名

```text
PlayerStatusArea
  HealthLabel
  MagicLabel
  MagicShieldLabel
  MagicDefenseLabel
  FormLabel
  ArousalLabel
  SensitivityLabel
  CorruptionLabel
  StatusContainer
```

## 敌人状态区

敌人状态区必须显示：

```text
敌人名称
生命值
魔力护盾
当前意图
意图数值
敌人状态
```

第一版敌人：

```text
堕落的学生
```

敌人意图示例：

```text
袭击：造成伤害，并提升发情值
瘴气护盾：获得魔力护盾
催眠光线：提升敏感值
```

### 建议节点命名

```text
EnemyView
  NameLabel
  HealthLabel
  MagicShieldLabel
  IntentIcon
  IntentNameLabel
  IntentValueLabel
  StatusContainer
```

## 手牌区

手牌区必须显示当前手牌。

每张卡牌至少显示：

```text
卡牌名称
费用
卡牌种类
效果描述
是否可用
```

第一版基础卡牌：

```text
星光变身
星光射击
魔力防御
```

### 卡牌可用状态

卡牌需要至少支持以下表现：

```text
可用
魔力不足
目标不合法
当前形态不可用
```

表现建议：

- 可用：正常亮度。
- 魔力不足：变灰。
- 目标不合法：拖拽时提示不可用。
- 当前形态不可用：变灰或显示锁定状态。

### 建议 CardView 节点

```text
CardView
  CostLabel
  NameLabel
  TypeLabel
  DescriptionLabel
  StateOverlay
```

如果有卡图，可以增加：

```text
ArtTexture
```

## 牌堆信息区

牌堆信息区必须显示：

```text
抽牌堆数量
弃牌堆数量
消耗区数量
```

显示示例：

```text
抽牌堆：8
弃牌堆：2
消耗区：0
```

### 建议节点命名

```text
PileInfoArea
  DrawPileCounter
  DiscardPileCounter
  ExhaustPileCounter
```

## 操作区

操作区最低需要：

```text
结束回合按钮
当前回合状态
```

当前回合状态示例：

```text
玩家回合
敌人回合
战斗胜利
战斗失败
```

### 建议节点命名

```text
ActionArea
  EndTurnButton
  TurnStateLabel
```

## 战斗日志

战斗日志强烈建议第一版就做。

它用于验证规则是否结算正确。

日志示例：

```text
玩家使用 星光变身。
玩家获得 70 点魔力防御。
玩家获得 3 点魔力上限。
玩家获得 3 点当前魔力。
玩家进入魔法少女形态。
玩家使用 星光射击。
堕落的学生受到 5 点普通伤害。
堕落的学生使用 催眠光线。
玩家敏感值提升 10。
```

### 建议节点命名

```text
BattleLogPanel
  LogText
```

## 目标选择与拖拽反馈

第一版卡牌交互至少支持：

```text
鼠标悬停卡牌
拖拽卡牌
拖到合法目标上时目标高亮
松开鼠标后尝试出牌
出牌失败时卡牌回到手牌
出牌成功时卡牌进入对应牌区
```

目标高亮对象：

```text
敌人
玩家自身
```

第一版不需要复杂箭头，可以只做目标高亮。

## 最低按钮和点击交互

第一版至少需要：

```text
点击结束回合
点击或拖拽卡牌
选择敌人目标
选择自身目标
```

如果 Axure 中暂时只画静态 UI，也要预留：

```text
卡牌区域
敌人可点击区域
玩家自身可点击区域
结束回合按钮
```

## Axure 原型交付建议

你在 Axure 中绘制 UI 时，建议至少包含这些文本标注：

```text
玩家状态区
敌人状态区
手牌区
牌堆信息区
结束回合按钮
战斗日志
敌人意图
```

如果某个 UI 元素只是装饰，不需要绑定逻辑，可以标注为：

```text
装饰
```

如果某个 UI 元素需要后续接逻辑，建议在 Axure 里标注它对应的功能名，例如：

```text
HealthLabel
MagicLabel
EndTurnButton
HandArea
EnemyView
```

## 最低战斗 UI 验收清单

一场最低战斗能跑起来时，UI 至少满足：

- 能看到玩家生命值。
- 能看到当前魔力和魔力上限。
- 能看到魔力护盾和魔力防御。
- 能看到玩家当前形态。
- 能看到发情值、敏感值、堕落值。
- 能看到敌人生命值。
- 能看到敌人魔力护盾。
- 能看到敌人意图。
- 能看到手牌。
- 能看出哪些牌能用、哪些牌不能用。
- 能点击结束回合。
- 能看到抽牌堆、弃牌堆、消耗区。
- 能通过状态图标看到变身状态。
- 能看到关键战斗日志。
- 能完成一次“星光变身 -> 星光射击 -> 敌人行动”的循环。
