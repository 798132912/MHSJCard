# 魔法少女卡牌游戏卡牌效果文档

日期：2026-05-19

本文档记录卡牌效果类型、效果字段、结算规则和第一版可用效果库。

相关文档：

- 设定、主题和资源含义：`游戏设定文档.md`
- 底层结算、牌区和公式：`规则机制文档.md`
- 效果实例、目标来源和触发时机：`效果时机流程文档.md`

本文档内容均为暂定，后续可以根据玩法测试继续修改。

## 设计原则

- 卡牌尽量由多个标准效果组合而成。
- 卡牌本身保存数据，具体执行交给效果系统。
- 同一类效果尽量复用同一个效果 ID。
- 复杂卡牌优先使用条件、分支和多段效果组合，不优先为单卡写专用逻辑。
- 成人向特殊属性只作为战斗数值和条件处理，角色按成人前提设计。

## 效果数据结构

每个效果建议使用统一结构：

```text

数值

伤害类型
资源类型
状态 ID
持续时间

```

示例：

```text
效果 ID：造成伤害
数值：6
目标：单个敌人
目标来源：继承卡牌目标
触发时机：附加时
伤害类型：魔力伤害
持续时间：瞬间
```

## 效果结算顺序

一张卡牌如果有多个效果，默认从上到下依次结算。

```text
检查使用条件
支付费用
按顺序为效果 1 创建效果实例
确定效果 1 的目标
将效果 1 附加到目标或战斗上下文
根据触发时机结算效果 1
根据持续时间决定是否移除效果 1
继续处理效果 2、效果 3
处理卡牌移动
检查死亡、解除变身、高潮状态等后置规则
```

如果某个效果导致战斗立即结束，则后续效果不再结算。

## 第一版效果库

### 造成伤害

用途：对目标造成指定类型的伤害。

字段：

```text
效果 ID：造成伤害
数值：伤害基础值
目标：敌人
伤害类型：普通伤害 / 魔力伤害 / 魅惑伤害 / 穿透伤害 / 真实伤害
```

结算：

- 魔力伤害会受到发情值降低。
- 魅惑伤害会受到发情值提升。
- 普通伤害按规则机制文档中的防御顺序结算。

示例：

```text
星光射击
费用：1
效果：
  - 造成 5 点魔力伤害
```

### 获得魔力护盾

用途：增加外层防御资源。

字段：

```text
效果 ID：获得魔力护盾
数值：护盾值
目标：自身
```

### 获得魔力防御

用途：增加维持变身的核心防御资源。

字段：

```text
效果 ID：获得魔力防御
数值：防御值
目标：自身
```

说明：

- 魔力防御降至 0 或以下时会解除变身。
- 该效果可用于变身卡牌，也可用于维持形态的补强卡牌。

### 获得魔力上限

用途：提升当前战斗中的魔力上限。

字段：

```text
效果 ID：获得魔力上限
数值：上限增加值
目标：自身
持续范围：本场战斗 / 当前变身期间 / 当前回合
```

第一版建议变身卡牌使用“当前变身期间”。

### 获得当前魔力

用途：增加当前回合可用魔力。

字段：

```text
效果 ID：获得当前魔力
数值：魔力值
目标：自身
```

计算：

```text
当前魔力 = min(当前魔力 + 获得值, 当前魔力上限)
```

如果卡牌明确写“可以超过上限”，则不套用上限限制。

### 进入变身状态

用途：让玩家进入魔法少女形态。

字段：

```text
效果 ID：进入变身状态
目标：自身
记录卡牌：是
```

结算：

```text
玩家获得变身状态
变身状态记录当前卡牌
当前卡牌由变身状态持有
```

变身卡牌通常组合以下效果：

```text
获得魔力防御
获得魔力上限
进入变身状态
```

字段：

字段：

```text
选择方式：玩家选择 / 随机 / 指定标签
```

### 施加状态

用途：给目标添加状态。

字段：

```text
效果 ID：施加状态
状态 ID：具体状态
层数：数值
持续时间：永久 / N 回合 / 本场战斗

```

第一版建议状态：

```text

易伤
虚弱

```

### 移除状态

用途：移除目标身上的状态。

字段：

```text
效果 ID：移除状态
状态 ID：具体状态
层数：数值或全部
目标：自身 / 敌人
```

### 增加发情值

用途：增加目标的发情值。

字段：

```text
效果 ID：增加发情值
数值：基础发情值
目标：自身 / 敌人
是否受敏感值影响：是 / 否
```

默认受敏感值影响。

结算：

```text
最终获得发情值 = ceil(基础获得发情值 * (1 + 敏感值 / 100))
变化后发情值 = clamp(变化前发情值 + 最终获得发情值, 0, 100)
如果发情值达到 100，触发高潮状态
```

### 降低发情值

用途：降低目标的发情值。

字段：

```text
效果 ID：降低发情值
数值：降低值
目标：自身 / 敌人
```

结算：

```text
变化后发情值 = max(0, 变化前发情值 - 降低值)
```

### 增加敏感值

用途：提高目标后续受到的发情值。

字段：

```text
效果 ID：增加敏感值
数值：增加值
目标：自身 / 敌人
持续时间：永久 / N 回合 / 本场战斗
```

### 降低敏感值

用途：降低目标后续受到的发情值。

字段：

```text
效果 ID：降低敏感值
数值：降低值
目标：自身 / 敌人
```

结算：

```text
变化后敏感值 = max(0, 变化前敏感值 - 降低值)
```

### 增加堕落值

用途：增加堕落值，用于条件、分支和特殊卡牌。

字段：

```text
效果 ID：增加堕落值
数值：增加值
目标：自身
```

### 条件效果

用途：根据条件决定是否执行某些效果。

字段：

```text
效果 ID：条件效果
条件：判断表达式
满足时效果列表
不满足时效果列表
```

示例：

```text
如果 堕落值 >= 20：
  造成 10 点魅惑伤害
否则：
  造成 5 点魔力伤害
```

### 按属性缩放

用途：根据某个属性改变效果数值。

字段：

```text
效果 ID：按属性缩放
基础效果
参考属性：发情值 / 敏感值 / 堕落值 / 魔力防御 / 魔力护盾
倍率或每档加成
```

示例：

```text
每 10 点发情值，额外造成 1 点魅惑伤害
```

### 改变卡牌费用

用途：临时或永久改变卡牌费用。

字段：

```text
效果 ID：改变卡牌费用
目标范围：指定卡牌 / 手牌 / 抽牌堆 / 本回合下一张牌
数值：费用变化
持续时间：本回合 / 本场战斗 / 永久
```

### 生成卡牌

用途：创建临时卡牌并放入指定牌区。

字段：

```text
效果 ID：生成卡牌
卡牌 ID
数量
目标牌区：手牌 / 抽牌堆 / 弃牌堆 / 消耗区
是否临时
```

### 检索卡牌

用途：从指定牌区寻找卡牌并移动到手牌。

字段：

```text
效果 ID：检索卡牌
来源牌区：抽牌堆 / 弃牌堆 / 消耗区
筛选条件：类型 / 标签 / 费用 / 名称
数量
```

## 已确定基础卡牌

### 星光变身

```text
名称：星光变身
费用：0
卡牌种类：变身
目标：自身
使用后牌区：由变身状态持有
消耗：否
效果：
  - 获得 70 点魔力防御
  - 当前变身期间获得 3 点魔力上限
  - 获得 3 点当前魔力
  - 进入变身状态
```

规则：

- 打出后不进入弃牌堆。
- 打出后不进入消耗区。
- 变身状态存在期间，星光变身由变身状态持有。
- UI 上通过状态图标显示变身状态，不显示变身暂存区。
- 当变身状态消失后，星光变身进入弃牌堆。

## 待定问题

- 发情值达到 100 后是否清空。
- 高潮状态是否只强制结束当前回合，还是还会附加其他惩罚。
- 魔力伤害和魅惑伤害是否都走普通防御顺序。
- 敌人是否也拥有发情值、敏感值和堕落值。
- 变身卡牌是否只能有一张，还是允许多个形态。
- 堕落值是否是战斗内临时值，还是跨战斗长期值。
