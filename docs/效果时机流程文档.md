# 魔法少女卡牌游戏效果时机流程文档

日期：2026-05-20

本文档记录卡牌效果、效果实例、目标选择、触发时机、持续时间和移除流程。

相关文档：

- 卡牌效果库和效果字段：`卡牌效果文档.md`
- 底层结算、牌区和公式：`规则机制文档.md`
- 数据表结构和配置表：`数据表结构说明.md`

本文档内容是战斗底层设计，后续代码实现需要优先遵守。

## 核心理解

本游戏的战斗流程以“时机”为核心。

卡牌本身不直接修改战斗数值。卡牌被使用时，会根据自身的效果列表生成一个或多个效果实例。效果实例会被附加到目标或战斗上下文中，并在指定时机触发。

简化流程：

```text
玩家使用卡牌
-> 卡牌生成效果实例
-> 效果实例确定目标
-> 效果实例附加到目标或战斗上下文
-> 到达触发时机
-> 效果实例生效
-> 根据持续时间决定保留或移除
```

## 卡牌与效果的关系

一张卡牌由一个或多个效果组成。

```text
Card
  Effect 1
  Effect 2
  Effect 3
```

卡牌只负责声明：

```text
有哪些效果
这些效果的基础参数
这些效果默认使用什么目标来源
这些效果默认在什么时机触发
这些效果持续多久
```

真正生效的是效果实例，而不是效果模板本身。

## 效果模板

效果模板是写在表格里的基础配置。

它描述“这个效果是什么”。

示例：

```text
效果ID：effect_normal_damage_5
效果类型：造成伤害
数值：5
伤害类型：普通伤害
默认触发时机：附加时
默认持续时间：瞬间
```

效果模板不会直接改变战斗状态。

## 效果实例

效果实例是在卡牌使用时生成的运行时对象。

它描述“这一次效果具体作用在谁身上、由谁产生、什么时候触发”。

一个效果实例至少需要记录：

```text
效果ID
来源卡牌ID
来源角色或敌人
目标
触发时机
持续时间
剩余持续时间
是否已经生效
附加参数
```

## 目标来源

效果的目标可以来自不同来源。

第一版目标来源：

```text
玩家选择目标
卡牌固定目标
效果自身选择目标
来源自身
随机合法目标
全部合法目标
无目标
```

### 玩家选择目标

玩家使用卡牌时，由玩家在 UI 中选择目标。

示例：

```text
星光射击
目标来源：玩家选择目标
目标类型：单个敌人
```

### 卡牌固定目标

卡牌在表格中已经指定目标。

示例：

```text
魔力防御
目标来源：卡牌固定目标
目标类型：自身
```

### 效果自身选择目标

效果在生效时根据规则选择目标。

示例：

```text
随机敌人
生命最低的敌人
拥有指定状态的目标
```

第一版可以先只支持随机敌人，复杂选择器后续再扩展。

## 触发时机

触发时机决定效果什么时候生效。

第一版核心时机：

```text
附加时
玩家回合开始时
玩家回合结束时
敌人回合开始时
敌人回合结束时
受到伤害前
受到伤害后
造成伤害前
造成伤害后
出牌前
出牌后
解除变身时
战斗结束时
```

### 默认触发时机：附加时

如果效果没有特殊说明，默认触发时机为：

```text
附加时
```

也就是说，效果实例被附加到目标后立刻生效。

绝大多数基础卡牌效果都使用这个时机。

## 持续时间

持续时间决定效果实例生效后是否继续保留。

第一版持续时间类型：

```text
瞬间
本回合
N 回合
本场战斗
直到条件满足
永久
```

### 瞬间

瞬间效果在生效完成后立刻移除。

示例：

```text
造成伤害
获得魔力护盾
抽牌
获得当前魔力
```

### 直到条件满足

效果会一直保留，直到指定条件满足。

示例：

```text
变身状态
持续时间：直到魔力防御 <= 0
```

## 附加与移除流程

### 附加流程

```text
创建效果实例
确定目标
把效果实例附加到目标或战斗上下文
检查触发时机
如果触发时机是“附加时”，立即结算效果
根据持续时间决定是否保留效果实例
```

### 移除流程

```text
效果持续时间结束
或
效果移除条件满足
或
效果被其他效果移除
-> 从目标或战斗上下文移除效果实例
-> 如果效果有离场处理，则结算离场处理
```

## 星光射击流程示例

卡牌：

```text
星光射击
费用：1 魔力
卡牌种类：法术
目标类型：单个敌人
效果：
  - effect_normal_damage_5
```

效果模板：

```text
效果ID：effect_normal_damage_5
效果类型：造成伤害
数值：5
伤害类型：普通伤害
目标来源：玩家选择目标
触发时机：附加时
持续时间：瞬间
```

使用流程：

```text
玩家选择星光射击
检查当前魔力是否 >= 1
玩家选择一个敌人作为目标
支付 1 点魔力
从手牌移除星光射击
根据 effect_normal_damage_5 创建效果实例
效果实例目标 = 玩家选择的敌人
效果实例附加到目标
触发时机 = 附加时，所以立即生效
对目标造成 5 点普通伤害
持续时间 = 瞬间，所以生效完成后立即移除效果实例
星光射击进入弃牌堆
检查死亡、解除变身、高潮状态等后置规则
```

## 星光变身流程示例

卡牌：

```text
星光变身
费用：0 魔力
目标类型：自身
效果：
  - 获得 70 点魔力防御
  - 当前变身期间获得 3 点魔力上限
  - 获得 3 点当前魔力
  - 进入变身状态
```

其中前三个效果是瞬间效果。

```text
触发时机：附加时
持续时间：瞬间
```

变身状态是持续效果。

```text
触发时机：附加时
持续时间：直到魔力防御 <= 0
```

变身状态需要记录来源卡牌：

```text
来源卡牌：星光变身
```

当变身状态被移除时：

```text
星光变身进入弃牌堆
玩家返回人类形态
魔力上限回到人类形态基础值
```

## 效果实例归属

效果实例可以归属到：

```text
玩家
敌人
卡牌
战斗上下文
```

第一版建议：

- 伤害、护盾、发情值变化等瞬间效果可以只在结算期间临时存在。
- 状态类效果附加到玩家或敌人身上。
- 变身状态附加到玩家身上，并记录来源卡牌。
- 全局规则类效果后续可以附加到战斗上下文。

## 后置检查

每次效果结算后，需要执行后置检查。

第一版后置检查顺序暂定：

```text
检查目标死亡
检查玩家死亡
检查解除变身
检查发情值是否达到上限
检查是否触发高潮状态
刷新 UI
```

如果后续发现顺序冲突，再在规则机制文档中统一调整。

## 表格设计影响

为了支持时机驱动，卡牌效果表需要包含这些字段：

```text
触发时机
持续时间
目标来源
移除条件
离场处理
```

第一版可以先给所有已有瞬间效果默认：

```text
触发时机：附加时
持续时间：瞬间
目标来源：继承卡牌目标
```

变身状态例外：

```text
触发时机：附加时
持续时间：直到条件满足
移除条件：魔力防御 <= 0
离场处理：来源变身卡牌进入弃牌堆
```

触发时机、持续时间和目标来源是代码层枚举，不单独作为策划配置表维护。枚举数字和含义记录在 `表格规范文档.md` 中。
