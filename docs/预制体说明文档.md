# 预制体说明文档

日期：2026-05-29

本文档归纳当前 Godot 工程中的 `.tscn` 预制体，说明它们的职责、脚本入口、主要节点和调整边界。

## 总览

当前项目预制体如下：

```text
scenes/combat/CombatScene.tscn
  战斗场景根预制体，负责当前 DEMO 战斗流程和战斗 UI 编排。

scenes/ui/CardView.tscn
  卡牌显示预制体，由战斗场景动态生成到手牌区。

scenes/ui/UnitView.tscn
  角色显示预制体，由战斗场景动态生成到玩家/敌人挂载点。
```

## CombatScene

路径：

```text
scenes/combat/CombatScene.tscn
```

脚本：

```text
scripts/ui/combat_scene.gd
```

作用：

- 当前主场景，也是最低战斗 DEMO 的战斗场景。
- 负责加载数据表、初始化玩家和敌人、构建牌堆、抽牌、出牌、敌人行动、效果结算和战斗日志。
- 负责战斗 UI 的整体编排，包括背景、顶部回合状态、手牌区、牌堆区、操作按钮、战斗日志、玩家当前魔力圆圈。
- 负责动态实例化 `CardView.tscn` 和 `UnitView.tscn`。

主要节点：

```text
CombatScene
├─ BackgroundFallback
├─ BackgroundTexture
├─ TopBar
│  └─ TurnStateLabel
├─ BattleArea
│  ├─ PlayerUnitSlot
│  └─ EnemyUnitSlot
├─ CenterArea
│  ├─ BattleLogPanel
│  └─ BattleLogToggleButton
├─ StatusArea
│  ├─ PlayerPanel
│  │  ├─ PlayerInfo
│  │  ├─ MagicIcon
│  │  └─ MagicValueLabel
│  ├─ EnemyPanel
│  ├─ PilePanel
│  └─ ActionArea
└─ HandPanel
```

动态生成内容：

- `BattleArea/PlayerUnitSlot` 下动态生成玩家 `UnitView`。
- `BattleArea/EnemyUnitSlot` 下动态生成敌人 `UnitView`。
- `HandPanel/Margin/HandList` 下动态生成手牌 `CardView`。

### 角色加载位置

`CombatScene` 不直接摆放玩家和敌人的角色图、生命条、魔力防御条，而是在战斗开始时动态实例化 `UnitView.tscn`。

脚本位置：

```text
scripts/ui/combat_scene.gd
```

实例化函数：

```text
_create_unit_views()
```

加载规则：

```text
player_unit_view = UnitViewScene.instantiate()
enemy_unit_view = UnitViewScene.instantiate()

player_unit_slot.add_child(player_unit_view)
enemy_unit_slot.add_child(enemy_unit_view)
```

玩家加载到：

```text
CombatScene/BattleArea/PlayerUnitSlot
```

当前挂载点参数：

```text
anchor_top = 0.5
anchor_bottom = 0.5
offset_left = 96
offset_top = -96
offset_right = 436
offset_bottom = 396
```

含义：

- 玩家挂载点在 `BattleArea` 左侧。
- 宽高约为 `340 x 492`。
- 在 1920 x 1080 窗口下，玩家 `UnitView` 左上角大致位于屏幕 `x = 120, y = 232`。

敌人加载到：

```text
CombatScene/BattleArea/EnemyUnitSlot
```

当前挂载点参数：

```text
anchor_left = 1.0
anchor_top = 0.5
anchor_right = 1.0
anchor_bottom = 0.5
offset_left = -436
offset_top = -172
offset_right = -96
offset_bottom = 320
```

含义：

- 敌人挂载点在 `BattleArea` 右侧。
- 宽高约为 `340 x 492`。
- 在 1920 x 1080 窗口下，敌人 `UnitView` 左上角大致位于屏幕 `x = 1460, y = 156`。

调整方式：

- 如果要移动玩家/敌人在战斗界面中的整体位置，调整 `CombatScene.tscn` 里的 `PlayerUnitSlot` / `EnemyUnitSlot`。
- 如果要调整角色图、生命条、魔力防御条在角色内部的位置，调整 `UnitView.tscn`。
- 不要在 `combat_scene.gd` 里写死角色图或资源条坐标。

注意：

- `PlayerUnitSlot` / `EnemyUnitSlot` 对齐的是 `UnitView` 根节点左上角。
- 角色图不是从 `UnitView` 根节点顶端开始显示，而是从 `UnitView/ImageArea` 开始显示。
- 当前 `UnitView/ImageArea.offset_top = 160`，所以角色图会比挂载点顶部再低约 `160` 像素。
- 当前敌人的意图图和名字位于角色图上方：`IntentArt.offset_top = 26`，`NameLabel.offset_top = 132`。
- 如果希望“挂载点看到的位置”和“角色图实际出现的位置”更接近，需要调整 `UnitView.tscn` 里的 `ImageArea`，而不是只移动 `EnemyUnitSlot`。

可调整内容：

- 战斗场景整体 UI 位置。
- 玩家/敌人的整体挂载点位置：`PlayerUnitSlot`、`EnemyUnitSlot`。
- 当前魔力圆圈位置：`StatusArea/PlayerPanel/MagicIcon` 和 `MagicValueLabel`。
- 抽牌堆卡背位置：`StatusArea/PilePanel/DrawPileCardBack` 和 `DrawPileCountLabel`。
- 结束回合、重新开始、日志按钮等战斗级按钮位置。

不建议放入的内容：

- 角色图像、角色生命条、角色魔力防御条的内部坐标。
- 单张卡牌内部布局。

这些内容应该分别放在 `UnitView.tscn` 和 `CardView.tscn` 中维护。

## CardView

路径：

```text
scenes/ui/CardView.tscn
```

脚本：

```text
scripts/ui/card_view.gd
```

作用：

- 单张卡牌的 UI 预制体。
- 由 `CombatScene` 在刷新手牌时动态实例化。
- 负责显示卡牌美术、卡框、费用、名称、描述、类型和不可用/待打出状态。
- 负责点击交互，并通过信号把点击的手牌索引传回战斗场景。

主要节点：

```text
CardView
├─ ArtTexture
├─ FrameTexture
├─ NameLabel
├─ DescriptionLabel
├─ TypeBadge
│  └─ TypeLabel
├─ CostBadge
│  └─ CostLabel
└─ StateOverlay
```

运行时数据来源：

- `Card.csv` 提供卡牌名称、费用、描述、类型、美术路径等。
- `combat_scene.gd` 的 `_card_display_data()` 负责组装显示数据。
- `card_view.gd` 的 `setup()` 负责把显示数据写入节点。

可调整内容：

- 卡牌整体尺寸：`CardView` 根节点。
- 卡图位置：`ArtTexture`。
- 卡框覆盖：`FrameTexture`。
- 名称、描述、类型、费用的 Label 位置和字号。
- 不可用或待选择状态遮罩：`StateOverlay`。

注意：

- `CardView` 根节点是 `Button`，它负责卡牌点击。
- 子节点大多应保持 `mouse_filter = Ignore`，避免挡住卡牌按钮点击。

## UnitView

路径：

```text
scenes/ui/UnitView.tscn
```

脚本：

```text
scripts/ui/unit_view.gd
```

作用：

- 单个战斗单位的 UI 预制体。
- 当前同时用于玩家和敌人。
- 由 `CombatScene` 动态实例化后分别挂到 `PlayerUnitSlot` 和 `EnemyUnitSlot`。
- 负责显示角色图像、角色名、生命条、魔力防御条、魔力护盾图标和条上数值。
- 敌人使用时还负责显示敌人意图文字和意图图。

主要节点：

```text
UnitView
├─ IntentLabel
├─ IntentArt
├─ NameLabel
├─ ImageArea
│  ├─ Placeholder
│  └─ Texture
└─ Bars
   ├─ HealthBar
   │  ├─ Empty
   │  ├─ FullClip
   │  │  └─ Full
   │  └─ HealthValueLabel
   ├─ MagicDefenseBar
   │  ├─ Empty
   │  ├─ FullClip
   │  │  └─ Full
   │  └─ MagicDefenseValueLabel
   └─ MagicShieldIcon
      ├─ Texture
      └─ MagicShieldValueLabel
```

运行时数据来源：

- 玩家数据来自 `Character.csv`。
- 敌人数据来自 `Enemy.csv`。
- 角色图像路径来自数据表中的 `battle_image_path`。
- 生命值来自运行时 `hp` / `max_hp`。
- 魔力防御条显示值来自运行时 `magic_defense`。
- 魔力护盾图标显示值来自运行时 `magic_shield`。

显示规则：

- 生命条始终显示。
- 魔力防御为 `0` 时隐藏 `MagicDefenseBar` 和 `MagicDefenseValueLabel`。
- 魔力防御大于 `0` 时显示空条、满条遮罩和数值。
- 魔力护盾为 `0` 时隐藏 `MagicShieldIcon`；大于 `0` 时显示护盾图标和当前护盾数值。
- 玩家护盾图标位于血条/魔力防御条右侧；敌人护盾图标位于血条/魔力防御条左侧。
- 当前魔力圆圈不属于 `UnitView`，它保留在 `CombatScene` 的 `PlayerPanel` 中。

可调整内容：

- 角色图位置和尺寸：`ImageArea`。
- 角色图实际显示节点：`ImageArea/Texture`。
- 占位色块：`ImageArea/Placeholder`。
- 生命条位置和尺寸：`Bars/HealthBar`。
- 魔力防御条位置和尺寸：`Bars/MagicDefenseBar`。
- 生命数字位置：`Bars/HealthBar/HealthValueLabel`。
- 魔力防御数字位置：`Bars/MagicDefenseBar/MagicDefenseValueLabel`。
- 魔力护盾图标位置和尺寸：`Bars/MagicShieldIcon`。
- 魔力护盾数字位置：`Bars/MagicShieldIcon/MagicShieldValueLabel`。
- 敌人意图位置：`IntentLabel`、`IntentArt`。

重要约定：

- 血条和魔力防御条的大小以预制体节点自身尺寸为准。
- `unit_view.gd` 不写死血条和魔力防御条的固定宽高。
- 血条和魔力防御条贴图直接挂在 `UnitView.tscn` 中，打开预制体应能直接看到。
- `unit_view.gd` 不负责加载血条和魔力防御条贴图，只负责运行时显示隐藏、数值和遮罩长度。
- 满条变化通过调整 `FullClip` 的宽度实现。
- `Full` 贴图尺寸会跟随对应条节点尺寸。
- `UnitView` 根节点宽度为 `404 px`，用于在资源条侧边预留魔力护盾图标区域。
- 魔力护盾图标资源使用 `assets/ui/resource_magic_shield.png`，源图规格为 `128 x 128 px` 透明 PNG，预制体显示尺寸为 `56 x 56 px`。
- 魔力护盾数字 Label 覆盖整个图标区域，居中显示，建议字号 `22`，浅色文字并使用深色描边。

调整建议：

- 如果要移动一整组资源条，优先移动 `Bars`。
- 如果只调整血条，移动或缩放 `Bars/HealthBar`。
- 如果只调整魔力防御条，移动或缩放 `Bars/MagicDefenseBar`。
- 如果只调整魔力护盾图标，移动或缩放 `Bars/MagicShieldIcon`；玩家默认在右侧，敌人运行时镜像到左侧。
- 如果希望数字始终跟随条，保持数字 Label 在对应条节点下面。

## 预制体职责边界

建议保持以下边界：

```text
CombatScene
  管战斗流程、战斗级 UI、动态挂载点、玩家当前魔力圆圈。

UnitView
  管单个角色图像、生命条、魔力防御条、魔力护盾图标、角色名、敌人意图。

CardView
  管单张卡牌的显示和点击。
```

如果后续继续拆分，可以优先考虑：

```text
PileView.tscn
  牌堆显示预制体，负责抽牌堆/弃牌堆/消耗区图像化显示。

BattleActionPanel.tscn
  战斗操作按钮预制体，负责结束回合、重新开始、日志按钮等。

StatusIconStack.tscn
  状态图标堆叠预制体，负责玩家和敌人的状态图标显示。
```
