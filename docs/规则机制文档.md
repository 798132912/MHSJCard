# 魔法少女卡牌游戏规则机制文档

日期：2026-05-19

本文档记录游戏底层规则、结算顺序、牌区流转、资源刷新、计算公式和特殊机制。

设定、主题和世界观请查看：`游戏设定文档.md`

卡牌效果库和卡牌效果组合请查看：`卡牌效果文档.md`

效果实例、目标来源和触发时机请查看：`效果时机流程文档.md`

敌人数据、敌人卡牌和敌人行为逻辑请查看：`敌人设计文档.md`

## 核心原则

- 规则机制与 UI 表现分离。
- 卡牌效果尽量数据驱动，由效果系统按时机统一结算。
- 战斗底层以触发时机为核心，卡牌使用时会生成效果实例。
- 牌区流转、伤害结算、状态触发必须有明确顺序。
- 当规则出现冲突时，以本文档的结算顺序为准。

## 战斗资源

### 生命值

- 生命值降到 0 或以下时，玩家战斗失败。
- 生命值通常不会在回合开始或回合结束时自动恢复。

### 魔力

魔力是打出卡牌所需的出牌资源。

- 当前魔力不能超过当前魔力上限，除非卡牌效果特别说明。
- 每个玩家回合开始时，当前魔力恢复到当前魔力上限。
- 打出卡牌时，先检查当前魔力是否大于等于卡牌费用。
- 出牌成功后，当前魔力减少卡牌费用。

计算公式：

```text
回合开始当前魔力 = 当前魔力上限
出牌后当前魔力 = 出牌前当前魔力 - 卡牌费用
```

### 魔力上限

- 人类形态下，基础魔力上限为 0。
- 魔法少女形态下，魔力上限通常由变身卡牌提供。
- 解除变身后，魔力上限回到人类形态基础值，暂定为 0。

### 魔力护盾

魔力护盾是外层防御资源。

- 普通伤害会先扣除魔力护盾。
- 魔力护盾默认不会在回合开始或回合结束时自动清空。
- 魔力护盾可以保护魔力防御，延长变身状态。

### 魔力防御

魔力防御是维持魔法少女形态的核心防御资源。

- 普通伤害在扣完魔力护盾后，才会扣除魔力防御。
- 魔力防御默认不会在回合开始或回合结束时自动清空。
- 当玩家拥有变身状态，并且魔力防御降到 0 或以下时，触发解除变身。

## 玩家基础参数

玩家需要设定基础每回合抽牌数量和手牌上限。

第一版暂定：

```text
基础每回合抽牌数量 = 5
基础手牌上限 = 10
```

后续卡牌、状态、遗物或事件可以临时或永久修改这些参数。

## 特殊属性

### 发情值

发情值是会影响战斗数值的累积属性。

- 发情值下限为 0。
- 发情值上限为 100。
- 发情值达到 100 时，触发高潮状态。
- 第一版暂定发情值不会在普通回合流程中自动衰减。
- 发情值不会在战斗结束后自动回归基础值，除非卡牌、事件或其他规则明确改变。

发情值变化公式：

```text
最终获得发情值 = ceil(基础获得发情值 * (1 + 敏感值 / 100))
变化后发情值 = clamp(变化前发情值 + 最终获得发情值, 0, 100)
```

发情值影响伤害的暂定公式：

```text
发情等级 = floor(发情值 / 10)
魔力伤害修正 = -发情等级
魅惑伤害修正 = +发情等级
```

示例：

```text
发情值 = 10
发情等级 = 1
魔力伤害 -1
魅惑伤害 +1
```

### 敏感值

敏感值用于放大受到的发情值。

- 敏感值下限为 0。
- 第一版暂定敏感值没有硬上限。
- 敏感值只影响“获得发情值”的结果，不直接影响生命值、魔力护盾或魔力防御。
- 敏感值不会在战斗结束后自动回归基础值，除非卡牌、事件或其他规则明确改变。

敏感值放大公式：

```text
最终获得发情值 = ceil(基础获得发情值 * (1 + 敏感值 / 100))
```

示例：

```text
基础获得发情值 = 8
敏感值 = 25
最终获得发情值 = ceil(8 * 1.25) = 10
```

### 堕落值

堕落值用于判断选项卡、事件选项和卡牌使用条件。

- 堕落值下限为 0。
- 第一版暂定堕落值没有硬上限。
- 堕落值不直接参与普通伤害结算。
- 堕落值可以作为卡牌使用条件、选项显示条件或效果分支条件。
- 堕落值不会在战斗结束后自动回归基础值，除非卡牌、事件或其他规则明确改变。

条件判断示例：

```text
如果 堕落值 >= 20：
  允许使用某张卡牌
否则：
  该卡牌不可使用或效果改变
```

### 高潮状态

高潮状态由发情值达到上限触发。

第一版暂定触发条件：

```text
发情值 >= 100
```

第一版暂定结算结果：

```text
赋予高潮状态
强制结束当前玩家回合
```

待定规则：

- 高潮状态是否持续到下回合。
- 触发后是否清空发情值。
- 触发后是否降低魔力防御、魔力护盾或当前魔力。
- 敌人回合触发高潮状态时是否立即跳过玩家的下一个回合。

## 形态规则

### 人类形态

- 战斗开始时，玩家默认为人类形态。
- 人类形态下，基础魔力上限为 0。
- 人类形态下，玩家通常只能打出 0 费卡牌或不需要魔力的卡牌。

### 魔法少女形态

- 打出变身卡牌后，玩家进入魔法少女形态。
- 魔法少女形态由“变身状态”表示。
- 变身状态会记录触发本次变身的变身卡牌。

### 解除变身

触发条件：

```text
玩家拥有变身状态
并且
魔力防御 <= 0
```

结算结果：

```text
移除变身状态
玩家返回人类形态
当前魔力上限 = 0
当前魔力 = min(当前魔力, 当前魔力上限)
本次变身对应的变身卡牌进入弃牌堆
```

## 牌区

### 牌区列表

第一版战斗至少包含以下牌区：

- 抽牌堆
- 手牌
- 弃牌堆
- 消耗区

### 抽牌堆

- 回合开始时从抽牌堆抽牌。
- 如果抽牌堆为空，并且还需要继续抽牌，则将弃牌堆洗牌后变成新的抽牌堆。
- 如果抽牌堆和弃牌堆都为空，则无法继续抽牌。

抽牌流程：

```text
需要抽 N 张牌
重复 N 次：
  如果抽牌堆为空：
    如果弃牌堆不为空：
      将弃牌堆洗牌后放入抽牌堆
      清空弃牌堆
    否则：
      停止抽牌
  从抽牌堆顶抽 1 张牌到手牌
```

### 手牌

- 玩家只能从手牌中打出卡牌。
- 手牌上限第一版暂定为 10。
- 如果抽牌时手牌已满，抽到的牌暂定直接进入弃牌堆。
- 玩家回合结束时，未打出的手牌进入弃牌堆。

### 弃牌堆

- 普通打出的卡牌在结算完效果后进入弃牌堆。
- 回合结束时未打出的手牌进入弃牌堆。
- 抽牌堆为空时，弃牌堆会被洗牌并转为新的抽牌堆。
- 解除变身时，变身状态记录的变身卡牌进入弃牌堆。

### 消耗区

- 带有消耗规则的卡牌在打出后进入消耗区。
- 消耗区中的卡牌本场战斗默认不会回到抽牌堆或弃牌堆。

### 变身状态持有卡牌

变身卡牌不需要作为独立可见牌区显示。

打出变身卡牌后，该卡牌由变身状态记录并持有。

- 打出变身卡牌后，该卡牌不进入普通弃牌堆。
- 打出变身卡牌后，该卡牌不进入消耗区。
- 变身期间，UI 只显示变身状态图标，不显示变身暂存区。
- 解除变身时，变身状态记录的变身卡牌进入弃牌堆。
- 如果后续允许多段变身或形态升级，需要重新定义变身状态可以持有几张卡牌，以及新旧变身卡牌的替换规则。

## 回合流程

### 战斗开始

```text
初始化玩家生命值
初始化玩家形态为人类形态
初始化当前魔力上限为 0
初始化当前魔力为 0
初始化魔力护盾为 0
初始化魔力防御为 0
读取玩家基础每回合抽牌数量
读取玩家基础手牌上限
初始化抽牌堆
洗牌抽牌堆
进入玩家回合开始
```

### 玩家回合开始

```text
结算玩家回合开始状态
当前魔力 = 当前魔力上限
抽取本回合手牌
刷新可出牌状态
等待玩家行动
```

第一版默认每回合抽牌数：5。

### 玩家行动

玩家可以重复执行：

```text
选择手牌中的一张卡牌
检查费用
检查目标
支付魔力
结算卡牌效果
移动卡牌到对应牌区
检查发情值是否达到上限
如果触发高潮状态，则强制结束当前玩家回合
检查死亡和解除变身
刷新 UI
```

### 玩家回合结束

```text
结算玩家回合结束状态
未打出的手牌进入弃牌堆
进入敌人回合
```

### 敌人回合

```text
敌人根据意图行动
结算敌人卡牌或技能效果
检查玩家死亡
检查解除变身
结算敌人回合结束状态
生成下一回合敌人意图
进入玩家回合开始
```

## 出牌结算顺序

基础出牌流程：

```text
1. 检查卡牌是否在手牌
2. 检查玩家是否满足卡牌使用条件
3. 检查当前魔力是否足够
4. 检查目标是否合法
5. 支付魔力
6. 从手牌移除卡牌
7. 根据卡牌效果列表创建效果实例
8. 确定每个效果实例的目标
9. 将效果实例附加到目标或战斗上下文
10. 按触发时机结算效果实例
11. 根据持续时间决定移除或保留效果实例
12. 根据卡牌规则移动到弃牌堆、消耗区，或由变身状态持有
13. 检查敌人死亡
14. 检查玩家死亡
15. 检查解除变身
16. 检查发情值是否达到上限
17. 如果触发高潮状态，则强制结束当前玩家回合
18. 刷新战斗状态
```

## 伤害结算顺序

### 普通伤害

普通伤害按以下顺序结算：

```text
原始伤害
-> 攻击方伤害加成
-> 防御方受伤修正
-> 最终伤害
-> 扣除魔力护盾
-> 扣除魔力防御
-> 扣除生命值
-> 检查解除变身
-> 检查死亡
```

基础计算公式：

```text
最终伤害 = max(0, 原始伤害 + 攻击方固定伤害加成)

魔力护盾扣除量 = min(魔力护盾, 最终伤害)
剩余伤害 = 最终伤害 - 魔力护盾扣除量

魔力防御扣除量 = min(魔力防御, 剩余伤害)
剩余伤害 = 剩余伤害 - 魔力防御扣除量

生命值扣除量 = 剩余伤害
```

### 魔力伤害

魔力伤害是受发情值削弱的伤害类型。

```text
发情等级 = floor(发情值 / 10)
最终魔力伤害 = max(0, 基础魔力伤害 + 攻击方固定伤害加成 - 发情等级)
```

魔力伤害计算出最终数值后，按照普通伤害的防御顺序结算。

### 魅惑伤害

魅惑伤害是受发情值强化的伤害类型。

```text
发情等级 = floor(发情值 / 10)
最终魅惑伤害 = max(0, 基础魅惑伤害 + 攻击方固定伤害加成 + 发情等级)
```

魅惑伤害计算出最终数值后，按照该卡牌或效果指定的伤害结算方式处理。第一版暂定魅惑伤害也走普通伤害防御顺序。

### 穿透伤害

穿透伤害暂定为无视魔力护盾，直接攻击魔力防御和生命值。

```text
最终伤害
-> 扣除魔力防御
-> 扣除生命值
-> 检查解除变身
-> 检查死亡
```

### 真实伤害

真实伤害无视魔力护盾和魔力防御，直接扣除生命值。

```text
最终伤害
-> 扣除生命值
-> 检查死亡
```

### 护盾破坏

护盾破坏只影响魔力护盾。

```text
护盾破坏值
-> 扣除魔力护盾
```

## 基础卡牌类型

每张卡牌至少拥有 1 个卡牌种类，也可以拥有多个卡牌种类。

第一版暂定卡牌种类：

- 攻击：主要造成伤害
- 技能：提供防御、抽牌、资源变化等效果
- 法术：通过魔力释放的主动卡牌类型
- 变身：进入魔法少女形态
- 状态：通常由敌人或特殊效果加入牌堆
- 诅咒：负面卡牌

## 基础卡牌移动规则

```text
普通卡牌打出后 -> 弃牌堆
消耗卡牌打出后 -> 消耗区
变身卡牌打出后 -> 由变身状态持有
变身解除后 -> 对应变身卡牌进入弃牌堆
回合结束未打出的手牌 -> 弃牌堆
```

这些数值用于基础战斗原型，后续可以调整。

```text
初始形态：人类形态
人类形态基础魔力上限：0
默认每回合抽牌数：5
默认手牌上限：10
基础变身卡牌提供魔力上限：3
基础变身卡牌提供当前魔力：3
基础变身卡牌提供魔力防御：70
初始魔力护盾：0
初始魔力防御：0
初始发情值：0
发情值上限：100
初始敏感值：0
初始堕落值：0
```
