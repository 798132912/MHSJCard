# Card.target 目标规则

`Card.csv` 的 `target` 字段现在只使用三类目标：

```text
1：自身
2：敌方单体
3：敌方群体
```

这些目标都按“出牌者阵营”解释，不再使用“玩家”这种固定阵营目标。

示例：

```text
玩家使用 target=1 的星光变身，只能选择玩家自己。
玩家使用 target=2 的星光射击，只能选择怪物。
怪物使用 target=2 的袭击，默认目标是玩家。
怪物使用 target=1 的防御行动，默认目标是怪物自己。
```

当前战斗只有一个怪物，所以 `3：敌方群体` 在结算上暂时等价于命中唯一敌方单位；后续多怪战斗可以在同一枚举下扩展成多个目标。
