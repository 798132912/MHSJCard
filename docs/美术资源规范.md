# 魔法少女卡牌美术资源规范

日期：2026-05-24

本文档记录第一版战斗 demo 所需美术资源的尺寸、格式、命名和表格配置规范。

当前目标是保证资源能稳定接入 Godot，并适配最低战斗界面。后续如果 UI 原型和动画系统升级，可以在本文档基础上扩展。

## 基础原则

- 资源文件统一放在 `assets/` 目录下。
- 文件名使用英文小写、数字和下划线，不使用中文、空格和特殊符号。
- 图片优先使用 PNG。
- 需要透明背景的角色、卡图、头像使用透明 PNG。
- 原始大图可以另外保存，但接入 Godot 的运行时资源按本文档尺寸导出。
- 表格中只填写 Godot 资源路径，例如 `res://assets/characters/player_star_battle.png`。

## 推荐目录

```text
assets/
  characters/
    玩家和怪物战斗图、头像
  cards/
    玩家卡牌图
  enemy_actions/
    怪物行动图
  ui/
    卡牌底图、图标、状态图标
  backgrounds/
    战斗背景
```

## 战斗单位资源

战斗单位包含魔法少女和怪物。

### 战斗图

用途：

```text
战斗界面中左右对峙的角色主图
```

推荐规格：

```text
尺寸：768 x 768 px
格式：PNG
背景：透明
安全区域：角色主体尽量控制在 680 x 680 px 内
朝向：玩家默认面向右，怪物默认面向左
```

第一版 demo 会把战斗图显示在约 `280 x 280` 的 UI 区域中，因此 768 图可以向下缩放，后续做更大角色展示也够用。

命名示例：

```text
assets/characters/player_star_battle.png
assets/characters/enemy_corrupted_student_battle.png
```

表格字段：

```text
Character.battle_image_path
Enemy.battle_image_path
```

### 头像

用途：

```text
状态栏、对话框、后续奖励或详情界面
```

推荐规格：

```text
尺寸：512 x 512 px
格式：PNG
背景：透明或纯色均可，透明优先
构图：头肩像，脸部清晰
```

命名示例：

```text
assets/characters/player_star_portrait.png
assets/characters/enemy_corrupted_student_portrait.png
```

表格字段：

```text
Character.portrait_path
Enemy.portrait_path
```

## 卡牌资源

### 卡牌插图

用途：

```text
玩家卡牌中间的插图区域
```

推荐规格：

```text
尺寸：512 x 384 px
比例：4:3
格式：PNG
背景：不要求透明
```

安全区域：

```text
主体内容不要贴边，四周至少预留 24 px
重要文字不要画进卡图，文字由 UI 渲染
```

命名示例：

```text
assets/cards/card_star_transform_art.png
assets/cards/card_star_shot_art.png
assets/cards/card_magic_defense_art.png
```

后续建议在 `Card` 表增加字段：

```text
art_path
```

### 卡牌底图

用途：

```text
CardView 背板、费用区、文本区
```

推荐规格：

```text
尺寸：360 x 520 px
比例：约 9:13
格式：PNG
背景：透明
```

命名示例：

```text
assets/ui/card_frame_player.png
assets/ui/card_frame_enemy.png
```

说明：

- 第一版可以先只提供一张通用卡牌底图。
- 后续可按卡牌类型扩展不同底图，例如攻击、法术、变身、状态。

## Godot 导入建议

像素风资源：

```text
Filter：Nearest
Mipmaps：关闭
```

非像素风资源：

```text
Filter：Linear
Mipmaps：按需要开启
```

透明 PNG：

```text
Alpha：保留透明
```

UI 图标：

```text
尽量导出为 128 x 128，再由 UI 缩放到实际显示尺寸
```

## 表格接入建议

当前已经有：

```text
Character.battle_image_path
Character.portrait_path
Enemy.battle_image_path
Enemy.portrait_path
```

建议下一步给 `Card` 表新增：

```text
art_path
frame_path
icon_path
```

第一版含义：

```text
art_path：卡牌或怪物行动插图
frame_path：卡牌底图，不填则使用默认底图
icon_path：小图标，主要用于敌人意图或快捷 UI
```

示例：

```text
card_star_shot.art_path = res://assets/cards/card_star_shot_art.png
card_enemy_assault.art_path = res://assets/enemy_actions/card_enemy_assault_art.png
```

## 程序占位规则

当资源路径为空或文件不存在时：

```text
战斗单位显示默认色块
卡牌显示文字按钮
敌人意图显示行动名称
```

这样可以保证策划表和战斗逻辑先跑通，美术资源后续逐步替换。
